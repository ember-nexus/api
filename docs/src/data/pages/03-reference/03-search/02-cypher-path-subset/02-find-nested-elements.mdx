This example uses a **variable length path** (`[:IS_MEMBER_OF*..]`) to find every `Plant` that is a member of the
taxon "Liliales", directly or through any number of intermediate taxonomic ranks, and limits the result to `5` matches
using Cypher's own `LIMIT` clause.  
Results are then [hydrated](/reference/search/element-hydration), i.e. transformed into a collection response.

Because the path length is unbounded, the resulting graph includes every intermediate taxon between each matching
plant and "Liliales" - not just the plants and the root taxon themselves.

**Note**: `LIMIT` restricts how many *paths* Cypher returns, which is not the same as `pageSize` on the Elasticsearch
query step - Cypher path query does not currently support pagination parameters of its own.
