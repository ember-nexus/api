This example uses Elasticsearch's [`prefix` query](https://www.elastic.co/docs/reference/query-languages/query-dsl/query-dsl-prefix-query)
to find all elements whose `name` starts with the string `blu`, and are accessible to the user.  
Results are then [hydrated](/reference/search/element-hydration), i.e. transformed into a collection response.

**Note**: `prefix` is a term-level query, so it is matched against the exact indexed value rather than an analyzed
text field - similar to [exact keyword matching](/reference/search/elasticsearch-query-dsl-mixin/exact-keyword-matching),
`name.keyword` should be preferred over `name` for reliable prefix matches on `text` fields.
