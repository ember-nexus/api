This example uses Elasticsearch's [`match` query](https://www.elastic.co/docs/reference/query-languages/query-dsl/query-dsl-match-query)
to perform a full text search of the word "lily" against the property `description` of all elements accessible to the
user.  
Results are then [hydrated](/reference/search/element-hydration), i.e. transformed into a collection response.

Every result contains the term "lily" somewhere in its description, including plants that are not lilies botanically -
Magnolia ("lilytree"), Daffodil ("Lent lily"), Desert Rose ("impala lily"). The Debug tab shows the relevance score of
each element; results are ordered by it, from 4.57 down to 1.44.
