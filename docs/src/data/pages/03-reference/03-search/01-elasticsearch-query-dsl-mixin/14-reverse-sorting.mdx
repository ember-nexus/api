This example is the [sorting example](/reference/search/elasticsearch-query-dsl-mixin/sorting) in descending order: the
full text search for "lily" is sorted by the name of the plants, but with `"order": "desc"`, so the results start with
the last name in alphabetical order. The search is restricted to plants, and only the first three results are returned.

The short notation `{"name.keyword": "desc"}` and the long notation `{"name.keyword": {"order": "desc"}}` are
equivalent. `metadata.sort` contains the values the results were sorted by.
