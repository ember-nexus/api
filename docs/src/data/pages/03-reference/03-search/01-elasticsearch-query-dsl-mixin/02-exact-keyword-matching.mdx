This example uses Elasticsearch's [`term` query](https://www.elastic.co/docs/reference/query-languages/query-dsl/query-dsl-term-query)
to retrieve all elements whose `name` has the exact same content as the provided query, "Bluebell", and are accessible
to the user.  
Results are then [hydrated](/reference/search/element-hydration), i.e. transformed into a collection response.

**Note**: Instead of querying the Elasticsearch property `name` directly, we use `name.keyword` for a more efficient
lookup. The `.keyword` suffix is part of Elasticsearch's automatic schema generation process. Manually managed schemas
might differ. See [their documentation](https://www.elastic.co/docs/reference/elasticsearch/mapping-reference/keyword)
for details.
