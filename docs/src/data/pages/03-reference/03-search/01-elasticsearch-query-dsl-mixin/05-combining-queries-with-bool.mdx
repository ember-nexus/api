This example uses Elasticsearch's [`bool` query](https://www.elastic.co/docs/reference/query-languages/query-dsl/query-dsl-bool-query)
to combine multiple smaller queries together, in this example using `OR` logic (`should` and `minimum_should_match`
value of `1`).  
Results are then [hydrated](/reference/search/element-hydration), i.e. transformed into a collection response.

Any element which has the word "blue" in its name _or_ its description is returned.  
Elements which mention the word "blue" in _both_ their name _and_ description have a higher score, and are usually
sorted towards the beginning of the response collection.
