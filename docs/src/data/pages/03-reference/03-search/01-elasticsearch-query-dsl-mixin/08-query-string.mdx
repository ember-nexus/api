This example uses Elasticsearch's [`query string` query](https://www.elastic.co/docs/reference/query-languages/query-dsl/query-dsl-query-string-query)
to perform a full text similar search across all elements accessible to the user, with in-query logic.  
Results are then [hydrated](/reference/search/element-hydration), i.e. transformed into a collection response.

**Note**: The query string must be properly formatted, as otherwise Elasticsearch itself will throw an error.
