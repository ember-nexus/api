The simplest way to use the element hydration step: providing a literal list of element ids directly in `query.elementIds`.
This is useful whenever the client already knows exactly which elements it wants, e.g. from a previous, unrelated
request, and just needs the full element objects.

As this is the only step in the request, there are no prior `stepResults` to build on - the three ids are hydrated
directly, in the order they were requested.
