method: put
name: Put element
endpointUrl: /<uuid>
swaggerUrl: /{uuid}

Replaces the data of the specified element.

**Note**: To change a relation the current user needs update access to its start node and read access to its end node, see
[Access to relations](/reference/access-model#access-to-relations).

**Note**: A handful of properties are reserved and can not be set through this request - see
[Reserved properties](/reference/security#reserved-properties).

**Note**: Changes take up to a second before they become searchable in Elasticsearch.
