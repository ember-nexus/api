---
endpoint: get-related
group: element
method: get
name: Get related
endpointUrl: /<uuid>/related
swaggerUrl: /{uuid}/related
---

Endpoint returns all nodes directly connected to a given central node, as well as the relations between the central and
outer nodes, regardless of type.

In the following example the id of the `Center {.hl-1}`-node is used in the `/<uuid>/related` endpoint, which will return the
following elements in the endpoint's response:

- the nodes `Parent {.hl-2}`, `Child {.hl-2}`, `Outer 1 {.hl-2}` and `Outer 2 {.hl-2}`
- both `OWNS {.hl-2}`-relations
- both `RELATED {.hl-2}`-relations

As the get related endpoint returns all nodes and relations regardless of type, it means that it can be considered to be
a **superset** of the get children and get parents endpoint. However, as this endpoint returns _every_ element directly
connected, the overall number of elements can be way higher.  
Use the specialized get children and get parents endpoint in situations, where only the ownership relation is relevant.
