This endpoint allows a user to change its own password. Knowledge of the currently used (old) password is required;
the user is identified by `uniqueUserIdentifier` rather than by the request's bearer token.

The new password is available immediately after the request.

Already created tokens remain valid up to their expiration date, i.e. changing the password does not revoke existing
tokens.

`newPassword` must be different from `currentPassword`, otherwise a `400 Bad Request` is returned. The default
anonymous user can not change its password and receives a `403 Forbidden` response instead.
