General error response. As this endpoint is static, it can not return specific details or logs for a previously sent
error response.

Returned when a resumable upload has expired (`PATCH /upload/<uuid>` after its `Expires` timestamp).

Example problem response body (`application/problem+json`):

```json
{
  "type": "https://api.example.com/error/410/gone",
  "title": "Gone",
  "status": 410,
  "detail": "Requested resource is no longer available and is expected to soon be permanently deleted."
}
```
