General error response. As this endpoint is static, it can not return specific details or logs for a previously sent
error response.

Returned by `GET /<uuid>/file` when the requested byte range starts beyond the end of the file or spans zero bytes (any range on a zero-byte file).

Example problem response body (`application/problem+json`):

```json
{
  "type": "https://api.example.com/error/416/range-not-satisfiable",
  "title": "Range Not Satisfiable",
  "status": 416,
  "instance": "urn:uuid:00000000-0000-0000-0000-000000000000",
  "detail": "Requested range start (999999999) is beyond the end of the resource (138937 bytes long).",
  "requestedStart": 999999999,
  "totalLength": 138937
}
```
