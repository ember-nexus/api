 Error 503 - Service Unavailable

 The HTTP 503 Service Unavailable server error response status code indicates that the server is not ready to handle
 the request, e.g. because it is overloaded or because a component of the service is not reachable. Retry the request
 after a short pause.

 Link to the documentation: https://ember-nexus.github.io/api

 Link to http.dev's explanation of the 503 error code: https://http.dev/503
